# 03 - PASANTÍA

## Entrega activa

Por indicación del usuario, la única entrega de Pasantía a mantener durante el desarrollo es la **bitácora** en `bitacora/`.

- `bitacora/REGISTRO_SESIONES.md` es el registro maestro resumido para consultar y retomar el historial. Actualizarlo al cierre de cada sesión de trabajo.
- `bitacora/YYYY-MM-DD.md` es la bitácora formal por fecha, con el formato de `bitacora/template.md`.

Actualizar ambos automáticamente al terminar cada sesión de trabajo del proyecto; no esperar un recordatorio.

No generar ni actualizar diagnóstico, propuestas, manual, informe final o evidencias como entregas activas, salvo que se soliciten expresamente.

No incluir en la bitácora contraseñas, secretos ni datos personales de productores. Registrar decisiones técnicas y usar ejemplos ficticios o anonimizados.
