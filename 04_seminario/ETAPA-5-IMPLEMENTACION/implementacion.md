# ETAPA 5 - IMPLEMENTACIÓN
Despliegue del frontend (Vercel/Netlify), publicación del Web App de Apps Script (acceso de ejecución), pruebas de integración y configuración de variables de entorno.

## Pasos
1. Publicar el Apps Script como Web App con acceso de ejecución y obtener la URL.
2. Configurar `VITE_APPS_SCRIPT_URL` y las credenciales de Firebase.
3. Build y despliegue en Vercel/Netlify.
4. Verificar la lectura/escritura real en la hoja Productores.
5. Configurar la PWA (manifest + service worker) para instalación en Android.
6. Prueba de carga offline y sincronización al reconectar.
