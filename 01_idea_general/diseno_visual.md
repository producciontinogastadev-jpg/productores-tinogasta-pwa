# DISEÑO VISUAL

## Objetivo
Muy visual (promoción pasantía + presentación). Funcional + atractivo, profesional, claro.

## Identidad visual
- Logo Municipalidad: usar como logo PWA / header
- Colores: primarios (verde/azul institucional), secundarios, acentos
- Tipografía legible móvil
- Dark/light coherente

## Elementos visuales
- Fotos: logo muni, íconos, fotos campo (capturas/fotos evidencias)
- Animaciones: transiciones suaves, skeletons, fade-in, loading, microinteracciones
- Gráficos: indicadores sync, badges, barras, estados
- Iconografía: Lucide/Tabler

## Componentes visuales
- Empty states con ilustraciones
- Cards, badges de estado (sync)
- Offline banner visual
- Spinners/loading
- Toasts notificaciones
