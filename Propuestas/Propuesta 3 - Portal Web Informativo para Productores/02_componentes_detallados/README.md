# 02 - COMPONENTES DETALLADOS (Propuesta 3)

Orientado a bycoding. Cada componente se define con: Propósito, Props, Estado interno, Eventos, Comportamiento, Validaciones, Estilos (Tailwind), Estructura JSX, Dependencias, Integración, Criterios de aceptación, Pruebas mínimas, Notas.

## Convenciones
- PascalCase (Hero.tsx, SeccionInformativa.tsx, ListaRequisitos.tsx, PasoTramite.tsx, AcordeonFaq.tsx, BotonWhatsApp.tsx, FormularioSolicitud.tsx)
- Ubicación `src/components`
- TypeScript obligatorio
- Tailwind CSS
- Sitio estático, mobile-first, sin backend propio
- Contenido en `src/content` (datos), componentes en `src/components`

## Alcance (MVP de pasantía)
Portal público e informativo, autocontenido. Puede integrar los módulos de las Propuestas 1 y 2 post-pasantía como portal central. Ver `VISION_SISTEMA.md`.
