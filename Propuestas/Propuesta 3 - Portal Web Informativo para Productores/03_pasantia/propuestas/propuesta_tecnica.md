# PROPUESTA 3 - TÉCNICA (Autocontenida)
Ver 02_componentes_detallados/ (tipos, servicios, flujos, hooks, componentes).

Resumen técnico:
- **Stack:** Astro + Vite + TypeScript (recomendado) o React + Vite; Tailwind CSS.
- **Contenido:** datos en `src/content` (secciones, requisitos, trámites, FAQ).
- **Contacto:** `whatsappService.buildLink` (Click-to-WhatsApp con mensaje preformateado).
- **Formulario ligero:** opcional, deriva a WhatsApp o Google Sheets (sin backend propio).
- **Despliegue:** Netlify/Vercel (publicación gratuita).
- **Sin login, sin base de datos propia.**
