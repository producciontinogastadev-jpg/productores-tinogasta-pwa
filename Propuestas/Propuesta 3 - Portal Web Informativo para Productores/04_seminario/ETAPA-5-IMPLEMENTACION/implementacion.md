# ETAPA 5 - IMPLEMENTACIÓN
Publicación del portal en Netlify/Vercel.

## Pasos
1. Definir el framework (Astro recomendado o React + Vite).
2. Cargar el contenido real (secciones, requisitos, trámites, FAQ) validado con la Secretaría.
3. Configurar el número de WhatsApp de contacto.
4. Build y despliegue en Netlify/Vercel.
5. Verificar en móvil (mobile-first) y accesibilidad básica.
