# ETAPA 6 - PRUEBAS

## Objetivo
Verificar que el portal es claro, navegable, correcto y utilizable desde el celular.

## Tipos de prueba
- **Componentes:** AcordeonFaq (abrir/cerrar), ListaRequisitos (render), PasoTramite (orden).
- **Integración:** BotonWhatsApp → link correcto con mensaje preformateado; FormularioSolicitud → derivación.
- **Responsive:** puntos de corte móvil/tablet/escritorio.
- **Contenido:** ortografía, claridad, enlaces válidos.
- **Accesibilidad:** contraste, foco, tamaños táctiles, `alt` en imágenes.

## Casos clave
- [ ] Botón WhatsApp abre el chat con el mensaje correcto.
- [ ] FAQ abre/cierra y no deja dos respuestas abiertas a la vez (si aplica).
- [ ] Navegación funciona solo con teclado.
- [ ] Vista móvil sin scroll horizontal.
- [ ] Formulario valida campos obligatorios antes de derivar.
- [ ] Contenido validado con la Secretaría.
