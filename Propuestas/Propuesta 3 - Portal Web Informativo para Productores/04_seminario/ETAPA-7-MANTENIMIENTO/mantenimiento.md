# ETAPA 7 - MANTENIMIENTO

## Enfoque
Sitio estático de muy bajo mantenimiento.

## Puntos de mantenimiento
- **Contenido:** actualizar secciones, requisitos, trámites y FAQ cuando cambien (editar el contenido del proyecto y redeploy).
- **WhatsApp:** mantener vigente el número de contacto.
- **Enlaces:** revisar periódicamente que no haya enlaces rotos.
- **Dependencias:** actualizar framework/Tailwind de forma esporádica.

## Riesgos
- Contenido desactualizado si no se asigna un responsable de actualizarlo.
- Cambios en la normativa de trámites (mitigado con revisión periódica).
