# Guía Seminario

**Para cátedra SEMINARIO – Presentaciones por etapas**

## Objetivo
Tener organizada toda la documentación, avances y entregables por etapas para presentar al profesor de Seminario.

## Uso
Crear una subcarpeta por etapa (Ej.: `Etapa 1`, `Etapa 2`, ...) con:
- Avances técnicos (capturas, scripts, archivos relevantes)
- Documentación solicitada para esa etapa (según lo que indique la cátedra)
- Justificación de lo realizado
- Dudas/respuestas si aplica

## Relacionado
- `documentacion/` – propuesta general/técnica
- `componentes/` – specs
- `guia_pasantia/` – documentación para pasantía (bitácora/informe)
