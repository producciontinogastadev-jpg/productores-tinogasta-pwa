# Layout - Estructura general

## Objetivo
Layout tras login. Topbar + menú hamburguesa + menú estático + área dinámica.

## Topbar (superior)
- Botón menú hamburguesa (abre drawer)
- Logo Municipalidad (logo PWA)
- Título app
- Estado: online/offline + pendientes sync (badge)

## Drawer hamburguesa
- Avatar/info usuario
- "Modificar mi perfil" (nombre, teléfono, info básica)
- "Cerrar sesión"
- Modo nocturno toggle
- Versión app

## Menú estático (lateral fijo desktop / bottom nav móvil)
Opciones:
- Inicio (bienvenida)
- Crear ficha
- Agregar/Modificar datos
- Buscar/Consultar fichas
- Fichas pendientes (sync)
- Ayuda (opcional)
- Modo nocturno

## Área contenido
- Al inicio: mensaje bienvenida corto "Bienvenido [nombre]"
- Al seleccionar opción → reemplaza bienvenida por vista correspondiente
