# Menú Estático

## Ubicación
Lateral (desktop) / Bottom nav (móvil). Siempre visible tras login.

## Opciones sugeridas (completas pero no excesivas)
1. Inicio - muestra bienvenida
2. Crear ficha - elegir rubro → formulario dinámico
3. Agregar datos - fichas nuevas
4. Modificar/Editar - buscar ficha o productor
5. Consultar/Búsqueda - ver fichas existentes
6. Pendientes sync (badge con contador)
7. Modo nocturno (toggle)
8. Mi perfil (acceso rápido)

## Sugerencia extra
- "Fichas del día" útil campo
- "Productores" buscar

Sugerencias para menú: quizás añadir "Productores" (buscar/editar productor) y "Fichas del día" (pendientes + hechas). Evitar sobrecargar.
