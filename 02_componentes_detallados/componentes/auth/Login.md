# Componente: Login

## Propósito
Pantalla de inicio de sesión (NO genérica). Email + contraseña.

## Props
Sin props externas (solo navegación)

## Estados
- email, password
- loading, error
- showPassword

## Validaciones
- email válido
- password mínimo 6

## Flujo
submit → signInWithEmailAndPassword → redirigir a app

## UI
Formulario centrado, responsive. Mensajes error claros.
