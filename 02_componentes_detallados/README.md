# 02 - COMPONENTES DETALLADOS

Orientado a bycoding. Cada componente debe definirse con: Propósito, Props, Estado interno, Eventos, Comportamiento, Validaciones, Estilos (Tailwind), Estructura JSX, Dependencias, Integración, Criterios de aceptación, Pruebas mínimas, Notas.

## Convenciones
- PascalCase (FormProductor.tsx, Buscador.tsx, Input.tsx, Boton.tsx, Alerta.tsx, Loader.tsx, CampoControl.tsx)
- Ubicación src/components
- TypeScript obligatorio
- Tailwind CSS
- Accesibilidad mínima (label asociado a id/name)
- API lógica en src/services
- Componentes puros + hooks
