# Guía Pasantía

**Para cátedra PASANTÍA – Documentación institucional**

## Objetivo
Registrar información necesaria para generar documentación solicitada por Pasantía: Diagnóstico Organizacional e Institucional, Diagnóstico Tecnológico, Bitácora, Informe Final, Propuestas, Manual de Usuario, entre otras.

## Incluir
- Cambios hechos (evolución del proyecto)
- Cómo se construyó / decisiones tomadas
- Evidencias (reuniones, validaciones, ajustes)
- Anotaciones para facilitar redacción de informe final
- Información para Manual de Usuario (flujo, capturas previstas)

## Relacionado
- `documentacion/` – base para propuestas/informe
- `componentes/` – referencia para Manual de Usuario
- `guia_seminario/` – avances por etapas
